## Confirmed defects and fixes

- Driver 0.32.0 invalidates snapshot IDs on every read. Including these IDs in
  the desktop fingerprint caused repeated replanning without actions. Ignore
  snapshot bookkeeping and timing, while still detecting actual UI changes.
- Multiple Calculator windows include UWP host/app windows. Inspect the active
  match or first visible matching host. When the requested app is missing,
  discover/launch it without capturing the unrelated foreground application's
  contents. This also avoids unnecessary private observation content.
- The live timeline previously deleted rows after 200 events. Keep all rows,
  restore missed events from SQLite after reconnect/heartbeat, and serialize
  WebSocket processing. Preserve the user's position when reading older rows.
- STOP now remains at the top of the right panel, with keyboard focus support.
- GGUF screenshots require a projector. Accept the real `qwen25vl` architecture
  spelling and use the installed MTMD handler. This Qwen vision architecture
  also requires the projector for text requests. Cancel through the supported
  logits processor, report native inference errors, and block model replacement
  while the old native computation is finishing.
- Default OpenRouter provider construction now requires explicit paid opt-in.
  Its existing free-route whitelist and DPAPI key storage remain enforced.
- Encode terminal/action consistency in the generation schema. Keep all runtime
  validation, approvals, fresh target tokens and evidence checks. Constrain
  generated handles to current tokens and remove stale handles from history.
- Normalize duplicated target representations, reject conflicting targets, and
  prefer UIA tokens over guessed pixels. Admission for an exact background
  window ignores unrelated foreground changes, while checking its own state.
- Remove duplicate observation/schema metadata from local prompts, provide
  enough context for images, and request disabled thinking when supported.
  Preserve readable runtime stuck/unverified-action errors.
- Add `--native-smoke-test` to verify the real WebView2 UI's authenticated
  WebSocket and idle runtime, then close through the normal launcher shutdown.
