# Chat workspace and local Qwen response repair

The task composer was below a scrollable model/control form. It now remains at the bottom of a full-height chat panel, with STOP and runtime controls at the top. Model selection and task details use progressive disclosure. Desktop observations and the full durable activity log remain visible alongside chat. No models, saved defaults or histories are replaced.

Qwen3-VL's Ollama parser starts in the thinking state even when the renderer honors `think=false`. Assistant prefill explicitly closes the thinking section for this architecture, keeping normal JSON schema validation and safe action admission. This is supported by the installed version's [renderer](https://github.com/ollama/ollama/blob/v0.34.4/model/renderers/qwen3vl.go) and [parser](https://github.com/ollama/ollama/blob/v0.34.4/model/parsers/qwen3vl.go), and verified through the existing local model. Other architectures use their existing request flow. Truncated responses still fail safely, now with a useful recovery message.

Validation:
- 61 unit/API/provider checks passed; 4 explicit live/browser opt-ins skipped in the default suite.
- Browser acceptance passed at 900×700, 1024×768, 1280×720, 1440×900, 760×1000, 390×844, 760×580 and 390×550. The composer, start button and STOP remain within the viewport without scrolling the task panel. Model save, provider settings, failed-task chat, history, 300+ event recovery, keyboard focus and Escape were exercised. An independent design review identified a narrow/short media-query collision; the follow-up review confirmed that fix resolved.
- Real `qwen3-vl:8b` structured verification returned valid JSON in 1.37 s, with 608 input and 14 output tokens; no desktop actions were involved in this probe.
- The subsequent real Calculator trial produced nine structured responses and four actions, then safely blocked on verification/action admission after 127.93 s. The incomplete-response defect is repaired on this tested path; autonomous Calculator completion remains unverified.

Private browser captures and live evidence stay in ignored `data/`. Release version: 0.1.2. Build and packaged native startup are validated before delivery.
